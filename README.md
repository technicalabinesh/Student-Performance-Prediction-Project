# Student Performance Prediction Project

This project analyzes student data and builds a machine learning model to predict student exam performance.

## Repository Contents

- `Student_Performance_Prediction_Project.ipynb` — main notebook containing data preprocessing, exploratory analysis, model training, and evaluation.
- `Student_Performance.csv` — dataset used for training and analysis.
- `LICENSE` — project license (Apache 2.0).

## Project Workflow

1. Load and inspect the dataset.
2. Preprocess features and target values.
3. Train prediction model(s).
4. Evaluate model performance with relevant metrics.
5. Interpret and compare results.

## How to Run

1. Open `Student_Performance_Prediction_Project.ipynb` in Jupyter Notebook or Google Colab.
2. Ensure the dataset file `Student_Performance.csv` is in the same directory.
3. Run notebook cells in order.

## Requirements

Use a Python environment with common data science libraries, such as:

- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`
- `scikit-learn`
- `jupyter`
